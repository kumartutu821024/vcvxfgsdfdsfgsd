## 🔍 What Happens Behind the Scenes

```
1. User opens http://localhost:8000
2. Browser loads index.html
3. JavaScript in app.js runs
4. app.js calls: fetch('/api.php/batches')
5. PHP processes request:
   - Routes to handleGetBatches()
   - Calls external API
   - Transforms data
   - Returns JSON
6. JavaScript displays data
7. Data cached for 5 minutes
8. Next request uses cache (faster)
```
